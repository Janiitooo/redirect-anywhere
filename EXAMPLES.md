# Examples

This repository includes four example branches, each redirecting to a different website.

| Branch | Destination |
|---|---|
| `janiito` | https://janiito.com |
| `rickyeditgames` | https://rickyeditgames.janiito.com |
| `studio` | https://studio.janiito.com |
| `piso-13` | https://piso-13.janiito.com |

## How to use

Each branch contains its own `index.html` file with the redirect URL already set.

Switch to the branch you want and use its `index.html` file as your redirect page.
