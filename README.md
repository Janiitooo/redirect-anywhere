# Redirect Anywhere

A simple HTML page that automatically redirects visitors to any website or URL.

## Usage

1. Download or clone this repository.
2. Open `index.html`.
3. Find `YOUR_URL_HERE` and replace it with your destination URL.
4. Save the file and upload it to your website.

That's it. Visitors will be automatically redirected to the URL you set.
